# StuddyBuddy AI

A web app that provides step-by-step explanations for Maths, Science and Physics questions, with notes, timetable and progress tracking.

Built for LaunchPad Hacks.

## Problem

Some students do not have access to a tutor at home. Some study apps require internet and use technical English, which can be difficult to follow. Data costs can also limit access.

## Intended Users

Grade 8-12 learners who study on a phone, use isiZulu and English, and have limited or no data access at home. Also for learners who want to plan study time and track study minutes.

## What It Does

1. Tutor: User selects Maths, Science or Physics, types a question, and receives a step-by-step explanation in isiZulu and English. Explanations are built into the app, so it works without internet.

2. Notes: User can create, save and delete notes. Notes are stored in the browser using localStorage.

3. Timetable: User can add a subject, time and task to build a study timetable.

4. Progress: User enters minutes studied. The app shows total minutes against a 60-minute daily goal and a progress bar.

## Demo

Live Demo: https://iduma2025study.github.io/Studybuddy-AI/

## Setup / How To Use

1. Open the demo link in a browser. No login or download is required.
2. Go to Tutor, select Maths, type "2x + 4 = 10", select Explain.
3. Go to Notes to save a note.
4. Go to Plan to add a timetable item.
5. Go to Progress to add study minutes.

No credentials or personal data are required.

## Technologies Used

HTML, CSS, JavaScript. Single file: index.html. localStorage for data storage. No server, no database, no API key.

## Work Completed During Hackathon Timeframe

All work was completed during the LaunchPad Hacks timeframe: idea, design, coding of Tutor, Notes, Timetable and Progress features, testing on mobile, README, LICENSE, and Devpost submission. No pre-existing code was used.

## Challenges

1. Offline functionality: Most tutor apps require internet. Explanations had to be built into the app to work without an API.
2. Language: Technical concepts had to be written in simple isiZulu and English.
3. Mobile use: The app had to work on small phone screens with low data use.

## What Was Learned

How to build a working prototype with HTML, CSS and JavaScript, how to use localStorage to save data in the browser, and how to design for users who need simple language.

## Limitations

The tutor covers a limited set of topics. It does not replace a teacher. It provides rule-based explanations, not a live AI model.

## Future Work
